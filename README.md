# React App

## Purpose

This project is a simple React application that demonstrates server‑side rendering, routing, and state management with Redux. It includes several example components such as a homepage, user list, search panel, and more, showcasing how to build a modern single‑page application.

## Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd <repo-directory>
   ```
2. **Install dependencies**
   ```bash
   npm install   # or yarn install
   ```
3. **Build the project**
   - Development build:
     ```bash
     npm run dev   # uses webpack.development.config.js
     ```
   - Production build:
     ```bash
     npm run build # uses webpack.production.config.js
     ```

## Usage

- **Development server**
  ```bash
  npm start   # runs the server with hot‑reloading (see development.js)
  ```
  Open `http://localhost:3000` in your browser.

- **Production**
  After building, start the server with:
  ```bash
  node server.jsx
  ```
  The app will be served on the configured port.
